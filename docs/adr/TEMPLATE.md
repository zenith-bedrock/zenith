# ADR §N — Short title in the imperative

> Part of the [decision log](README.md). Code and docs cite this record as `ADR §N`.

**Context:** What forced the decision: the measurement, the bug, the audit finding or the feature that cannot be built without it. Link the evidence (a test, a profile, a reference implementation) rather than describing it from memory.

**Choice:** What we do, stated so that a reader can tell whether a given change obeys it.

**Why:** The alternatives that were considered and why they lost. Name the reference implementations looked at (PocketMine, Dragonfly, Minestom, Cuberite, BDS) and whether their technique applied.

**Invariants:** What must stay true afterwards, and the test or build step that guards it. If nothing guards it, say so.

**Non-goals:** What this deliberately does not do.

**Deferred:** What is left for later and what would trigger doing it.

**Verification:** The tests added or changed, and any run against a real client (`Smoke`) with its limits. Say what was *not* measured.

**Status (month year):** Proposed, Shipped, or Superseded by §N, with the files that carry it.
